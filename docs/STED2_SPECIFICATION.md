# STed2.07m オリジナル仕様書

## 1. この仕様書について

本書は、`STed2.07m` のソースコード、付属マニュアル、設定ファイル、データ形式処理を読み取り、元のプログラムが提供している機能と前提を再構成した仕様書である。

逐語訳や移植設計書ではなく、後続の macOS/iOS 移植方針を検討するための基準文書とする。ソースコードと付属文書から確認できた事実を「確定仕様」とし、実機や外部プログラムが必要で確認できないものは「要確認」として記載する。

## 2. 製品概要

### 2.1 一文でいうと

STed2.07m は、X680x0 上で MIDI 演奏データを作成・編集・記録・再生する、最大 36 トラックの MIDI シーケンサ／ミュージックコンポーザである。

### 2.2 製品の本質

STed2.07m の中心は、音声を合成することではなく、次の処理である。

1. MIDI 演奏データをトラック単位で保持する。
2. ノート、タイミング、音量、各種 MIDI コントロール、システム・エクスクルーシブを編集する。
3. 楽曲のテンポ、拍子、調、トラックの MIDI チャンネルや音色割り当てを管理する。
4. 既存の RCP/R36 データを読み込み、RCP/R36 として保存する。
5. 再生時にはデータを X680x0 の常駐 MIDI ドライバ `RCD.x` に渡し、接続された外部 MIDI 音源を鳴らす。

したがって、元の STed2.07m は単独で音を出すソフトウェア・シンセサイザではない。MIDI 入出力と再生の実体は、RCD ドライバ、MIDI インターフェース、外部音源、必要に応じて `RCP.x` や `TE.x` などの外部プログラムに分かれている。

### 2.3 想定ユーザーと用途

- X680x0 と外部 MIDI 音源を使って曲を打ち込みたい作曲者。
- RCP/R36 形式の既存曲を修正・再構成したいユーザー。
- リアルタイム演奏を録音し、後からクオンタイズやベロシティ調整をしたいユーザー。
- Roland CM-64、SC-55、SC-88 などの音源を前提に、音色・リズム・エクスクルーシブを曲データと一緒に管理したいユーザー。
- 楽器を使わず、内蔵キーボードエミュレータやステップ入力で入力したいユーザー。

## 3. 製品スコープ

### 3.1 含まれる機能

- 18 トラック RCP と 36 トラック R36 の読み書き。
- 最大 36 トラックのトラック設定・編集・コピー・交換・ミックス。
- リアルタイム録音、ステップ入力、通常の文字／数値入力。
- 単音・和音・休符・タイ・スラーを含むノート編集。
- MIDI チャンネル、プログラムチェンジ、バンク、各種 CC、アフタータッチ、ピッチベンド、テンポの編集。
- MIDI システム・エクスクルーシブの入力、表示、編集、送信。
- 楽譜表示と MIDI コントローラのグラフ表示。
- 音源定義ファイルによる音色名・バンク・リズム名の表示。
- CM-64、SC-55、SC-88 系の音源制御データの作成・管理。
- トラック／パート／リズム／ユーザー・エクスクルーシブの補助ファイル入出力。
- 設定ファイルによるキーバインド、表示、外部コマンド、ファイルパスの変更。
- X680x0 キーボードを使った簡易 MIDI キーボードエミュレータ。

### 3.2 元の製品に含まれないもの

- 内蔵ソフトウェア音源。
- オーディオ録音・波形編集・ミックスダウン。
- オーディオファイルの再生や書き出し。
- DAW のようなオーディオトラック、プラグイン・ホスト、ミキサー。
- 標準 MIDI ファイルの完全なネイティブ入出力。設定された外部変換プログラム経由で扱う構成はあるが、STed の主要ファイル形式ではない。
- 現代的なウィンドウ、マウス、タッチ操作。

## 4. 用語とドメインモデル

### 4.1 楽曲

楽曲は、次の情報を持つ一つの編集単位である。

- タイトル：最大 64 文字。
- ファイル名。
- 全体テンポ。
- タイムベース。
- 拍子の分子・分母。
- 調号と長調／短調、シャープ／フラット表示。
- Play Bias：再生時の全体的なタイミング補正。
- 12 行の楽曲メモ。
- 最大 36 個のトラック。
- パート音色割り当て。
- リズム割り当て。
- ユーザー・エクスクルーシブ定義。
- CM-64／SC-55 系の初期化・制御データ。

### 4.2 トラック

トラックは、時間順の MIDI イベント列と、その演奏・表示属性を持つ単位である。

トラックごとに次を設定できる。

| 属性 | 内容 |
| --- | --- |
| Track No. | 1～36 の番号 |
| Mode | Play、Mute、Mix、Rec |
| MIDI Channel | A1～A16、B1～B16、または OFF。内部的には最大 32 の論理チャンネル |
| ST+ | トラック全体の発音タイミング補正。-99～+99 |
| K#+ | ノート番号補正。-64～+63 または OFF |
| RHY | リズムトラック指定。OFF、ON、ON+ |
| Memo | トラックメモ。最大 36 文字 |

Mode の意味は次のとおりである。

- `Play`：通常再生する。録音中にも再生対象になる。
- `Mute`：再生しない。録音時の既存データも鳴らさない。
- `Mix`：既存データを鳴らしつつ、録音データを既存トラックへ混ぜる。
- `Rec`：録音先になる。複数トラックを `Rec` にするとマルチトラック録音になる。

### 4.3 イベント

トラック内部は、基本的に 4 バイト単位のイベント列として保持され、終端にトラック終端コードを置く。

通常のノートイベントは次の意味を持つ。

| フィールド | 意味 |
| --- | --- |
| NOTE/K# | MIDI ノート番号。通常 0～127 |
| ST | 前イベントからの開始時刻差 |
| GT | ゲートタイム／発音長 |
| VEL | ベロシティ。通常 1～127 |

同じ発音時刻の和音は、同時刻を表す ST=0 のノートを連続させることで表現する。内部には、長い待ち時間、コメント、繰り返し、同一小節参照、特殊 MIDI イベントなど、通常ノート以外のレコードも存在する。

主な内部イベント種別は次のとおりである。これは互換実装のための内部語彙であり、すべてを画面上の同じ形式で表示する必要はない。

| 種別 | 用途 |
| --- | --- |
| Note | ノートオン／ノートオフ相当の音符情報 |
| User Exclusive | ユーザー定義エクスクルーシブ 0～7 |
| Track Exclusive | トラック固有エクスクルーシブ |
| Roland Base / Parameter / Device | Roland 系システム・エクスクルーシブの短縮表現 |
| MIDI Channel | 発音チャンネル変更 |
| Tempo | 途中テンポ変更、テンポグラデーション |
| Program / Bank+Program | プログラムチェンジ、バンクセレクト付き音色変更 |
| Control Change | 任意 CC、音量、パン、モジュレーション等 |
| Channel / Poly Aftertouch | チャンネル・アフタータッチ、ポリ・アフタータッチ |
| Pitch | ピッチベンド |
| Comment | トラック内コメント |
| Repeat Start / End | 繰り返し範囲 |
| Same Measure | 既存小節への参照 |
| Measure Line | 小節境界 |
| End of Track | トラック終端 |

### 4.4 時間

- 初期タイムベースは 48。
- UI で選択できるタイムベースは 48、60、80、96、120、160、192、240、384、480。
- テンポは UI 上 10～240 BPM を基本とし、内部イベントではより広い値域を扱う。
- 4/4 拍子では、タイムベース 48 の 4 分音符が 48 ステップ。
- ST は待ち時間、GT は音符の長さとして扱う。
- 元マニュアルの目安では、4 分音符の ST は 48、通常の GT は 30～40、レガートは 40～48、スタッカートは 8～24 程度。
- 長い時間差や長い音価は、内部の継続レコードを含む複数レコードに分割される場合がある。

### 4.5 共有小節と圧縮表現

同じ内容の小節を `SAME MEAS` で参照したり、繰り返し範囲を記録したりできる。編集やポイント再生時には、必要に応じてこれらを展開して実際のイベント列として処理する。

このため、トラックには「表示・編集用の圧縮表現」と「再生用に展開された表現」が存在し得る。移植時は、元形式を壊さず保存できる表現と、検索・再生・編集しやすい正規化表現の責務を分ける必要がある。

## 5. ユーザーインターフェース

### 5.1 メイン画面

メイン画面は、楽曲全体と 36 トラックの状態を一覧できる画面である。表示される主な情報は次のとおり。

- 空きメモリ、使用メモリ。
- 楽曲タイトル。
- 現在のファイル名。
- テンポ、タイムベース、Play Bias、拍子、調。
- MIDI IN の状態。
- トラック番号、Mode、MIDI チャンネル、ST+、K#+、RHY、メモ、ステップ数、総ステップ数。

画面上は一度に 18 トラック程度を表示し、ページ操作で 1～18 と 19～36 を切り替える。ただし編集対象のデータモデルは常に 36 トラックである。

### 5.2 メインコマンド

メインメニューには、概ね次の 18 コマンドがある。

1. `LOAD`：RCP/R36 と補助データの読み込み
2. `SAVE`：RCP/R36 の保存
3. `EDIT & SET`：トラック選択とトラック属性設定
4. `PLAY`：楽曲再生
5. `RECORD`：MIDI リアルタイム録音
6. `FILTER`：録音・入力 MIDI フィルタ
7. `TIME & KEY`：テンポ、拍子、調、タイムベース設定
8. `TITLE`：タイトル編集
9. `MEMO`：楽曲メモ編集
10. `PART ASS`：パート／音色割り当て
11. `RHY ASSI`：リズム音色割り当て
12. `USER EXC`：ユーザー・エクスクルーシブ編集
13. `CM64 CON`：CM-64 関連制御
14. `SC55 CON`：SC-55／SC-88 関連制御
15. `OPTION`：設定・外部コマンド・各種オプション
16. `UNIT SEL`：編集単位や選択方法の変更
17. `INIT`：楽曲データ初期化
18. `EXIT`：終了とドライバへのデータ反映

### 5.3 トラックエディタ

トラックエディタは、イベントを時系列の行として表示・編集する。主な表示列は次のとおり。

- `MEAS`：小節番号。
- `STEP`：イベントまでのステップ。
- `NOTE/K#`：音符番号または特殊イベント。
- `ST`：開始時間差。
- `GT`：ゲートタイム。
- `VEL`：ベロシティ。

主な編集操作は次のとおり。

- カーソル移動、ページ移動、小節移動、タグ移動。
- 検索、置換、削除。
- 範囲選択、コピー、カット、ペースト、ミックス、反転。
- 複製、繰り返し、和音の並べ替え。
- ST、GT、VEL の一括変更、ランダム化、オフセット。
- クオンタイズ、休符・音符・ベロシティ・エクスプレッションの最適化。
- コードの上下移調、キー／スケール処理。
- コメント、小節線、リピート、SAME MEAS の操作。
- MIDI 特殊コントローラとエクスクルーシブの入力・編集。
- ノート／コントローラ／ピッチ等の分離と結合。
- Undo。

### 5.4 入力モード

編集時の MIDI 入力には、次のモードがある。

- `EDIT`：通常の文字・数値による編集。
- `EDIT SOUND`：音色・音源に関連する編集。
- `EDIT MIDI IN (MONO)`：MIDI 入力を単音として取り込む。
- `EDIT MIDI IN (POLY)`：MIDI 入力を和音として取り込む。
- `EDIT MIDI IN (STEP)`：MIDI キー入力を使ったステップ入力。
- `EDIT MIDI IN (P/ST)`：ピッチ／ステップ系の複合入力。

ステップ入力では、設定したキー番号から ST／GT を算出し、和音の後に次の長さへ進む操作を行える。

### 5.5 グラフィック表示

楽譜表示では、音符、符尾、小節線、調号、音価を表示する。グラフ表示では、音量、パン、モジュレーション、エクスプレッション、ピッチ、テンポ、アフタータッチ、任意 CC、エクスクルーシブ等を時間軸上で表示・編集する。

ビジュアル編集では、直線、ランダム、正弦波、三角波、ピーク、バレー等の形状を生成し、範囲のカット、連結、分割、ミックスができる。

## 6. 再生仕様

### 6.1 標準再生

1. 各トラックの Mode、MIDI チャンネル、ST+、K#+、RHY を反映する。
2. Mute トラックを除外し、必要なら SAME MEAS や repeat を展開する。
3. 楽曲ヘッダ、初期音色、CM-64／GS データ、初期エクスクルーシブを準備する。
4. 全トラックを RCD が扱う形式にシリアライズする。
5. 常駐 `RCD.x` の初期化・転送・再生開始 API を呼ぶ。
6. RCD が MIDI バイト列を外部 MIDI 音源へ送信する。

RCD の再生状態、テンポ、総ステップ数、トラック位置、MIDI 入出力状態などは、RCD の共有ヘッダを介して STed から参照される。

### 6.2 ポイント再生

カーソル位置、小節、タグ等を起点にした部分再生ができる。部分再生では一時的な RCP バッファを作り、開始位置より前の音色・コントローラ・テンポなど、再生に必要な直近の状態を補ってから RCD に渡す。

### 6.3 パネル再生

設定により、RCP のパネル表示を担う外部 `RCP.x` を呼び出す。歌詞・ワード表示用の `.WRD` が存在する場合は、それと連携する構成がある。

### 6.4 外部コマンド

設定ファイルの `#mplay` や `#program` で、再生前後または変換時に外部コマンドを実行できる。外部コマンドには、音源データ変換、RCP／標準 MIDI／他シーケンサ形式との変換、LZM 圧縮などが含まれる。

外部コマンドの存在や個別の引数は、STed 本体だけでは保証されない。

## 7. 録音仕様

### 7.1 リアルタイム録音

RCD から MIDI バイト列を受け取り、MIDI の running status を含む入力ストリームをデコードしてトラックイベントへ変換する。

対応する主な入力は次のとおり。

- ノートオン／ノートオフ。
- プログラムチェンジ、バンクセレクト。
- コントロールチェンジ。
- チャンネル・アフタータッチ、ポリ・アフタータッチ。
- ピッチベンド。
- システム・エクスクルーシブ。

ノートオンのベロシティ 0 はノートオフとして扱う。ノートオンとノートオフの間隔から GT を計算し、タイムベースに基づく ST／GT へ変換する。

### 7.2 録音開始・終了

録音開始は、MIDI IN、Return、Space、または MIDI Start などの操作・同期条件から選択できる。録音の開始小節・終了小節、メトロノーム、MIDI THRU、入力フィルタを指定する。

停止時は録音ストリームを終端処理し、対象トラックに `End of Track` を付ける。キャンセル時は録音結果を破棄する。

### 7.3 録音先

- Rec トラックが 1 本ならシングルトラック録音。
- Rec トラックが複数なら、入力チャンネルに応じて複数トラックへ振り分ける。
- Mix トラックでは、入力を既存データへ混ぜる。
- トラックごとのチャンネル変換、キートランスポーズ、フィルタ設定を適用する。

### 7.4 録音中のモニター

録音中の MIDI モニターでは、入力された MIDI データを表示し、必要に応じて出力へスルーする。システム・エクスクルーシブは 16 進表記で確認できる。プログラム選択やチャンネル変換をモニター画面から送信できる。

## 8. MIDI・音源制御

### 8.1 特殊コントローラ

通常の MIDI イベントに加えて、画面上で意味を持つ短縮記号を使える。主なものは次のとおり。

| 記号 | 意味 |
| --- | --- |
| `G` | プログラムチェンジ |
| `G@` | バンク＋プログラム |
| `M` | MIDI チャンネル変更 |
| `T` | テンポ |
| `P` | ピッチベンド |
| `C` | チャンネル・アフタータッチ |
| `K` | ポリ・アフタータッチ |
| `L` | 任意の CC |
| `D` | モジュレーション |
| `V` | ボリューム |
| `N` | パン |
| `E` | エクスプレッション |
| `H` | ホールド 1 |
| `A` | 全コントローラリセット |
| `@` / `@@` | バンク MSB / LSB |
| `F1` / `F3` / `F4` | リバーブ／コーラス／ディレイ |
| `PT` / `PO` / `PC` | ポルタメント・タイム／オンオフ／コントロール |
| `SS` / `ST` / `BR` | ソステヌート／ソフト／ブレス |
| `NM` / `NL` | NRPN MSB / LSB |
| `RM` / `RL` | RPN MSB / LSB |
| `U0`～`U7` | ユーザー・エクスクルーシブ |
| `X` | トラック・エクスクルーシブ |
| `B` / `R` / `I` | Roland 系アドレス／パラメータ／機種指定 |

### 8.2 音色定義ファイル

`.DEF` ファイルは、音源機種ごとの表示名と送信情報を外部化する。定義には概ね次を含む。

- 音源モジュール名、機種 ID。
- GM、GS、拡張モードなどのモード。
- バンクとプログラムの対応。
- パートごとの音色名。
- 32 論理チャンネルへの音色リスト割り当て。
- リズム音色定義。
- PCM カード名とカード番号。
- 音源切替時の待ち時間。
- ミュート対象や表示グループ。

標準付属定義には CM-64、SC-55、SC-88 系がある。定義形式を使うことで、STed 本体の編集モデルを特定音源から切り離せる。

### 8.3 CM-64 制御

CM-64 の LA 音色、PCM パッチ、リズムパッチ、音色・ティンバー関連データを扱う。CM-64 の制御データは `.CM6` として保存できる。一部の音色編集は外部 `TE.x` に依存する。

### 8.4 SC-55／SC-88 制御

SC-55／SC-88 の GS 制御情報を扱い、`.GSD` データを読み込む。詳細な音源操作は外部 `GE.x` 等との連携を前提とする箇所がある。

### 8.5 ユーザー・エクスクルーシブ

- 最大 8 個のユーザー定義メッセージ。
- 各メッセージは最大 24 バイト程度の 16 進データを編集。
- `gt`、`ve`、`ch`、`cs`、`ss`、`F7` などの置換記号を使い、ゲート、ベロシティ、チャンネル、チェックサム等を埋め込める。
- 全定義を `.REX`、個別定義を `.RES` として保存・読み込み。
- Roland 系メッセージではチェックサム生成を支援する。

## 9. ファイルとデータ形式

### 9.1 楽曲ファイル

| 拡張子 | 役割 | 仕様上の位置づけ |
| --- | --- | --- |
| `.RCP` | 18 トラック RCP 互換楽曲 | 主形式。Recomposer／98 v2.5F 系と互換を意図 |
| `.R36` | 36 トラック楽曲 | STed 拡張形式 |
| `.MDF` | 圧縮・配布用データ等 | LZM 等の外部処理と関連。楽曲本体の正規形式ではない場合がある |
| `.WRD` | 歌詞・ワード表示 | パネル再生時に外部 RCP と連携 |

`.RCP` は 18 トラック、`.R36` は最大 36 トラックを持つ。18 トラックを超える使用トラックがある場合は、設定に応じて R36 保存になる。読み込み時のシフト操作で、後半トラックへ読み込む機能がある。

RCP ヘッダには、タイトル、メモ、テンポ、タイムベース、拍子、調、Play Bias、音源ファイル名、リズム割り当て、ユーザー・エクスクルーシブ等が格納される。

### 9.2 トラック・補助ファイル

| 拡張子 | 役割 |
| --- | --- |
| `.TRK` | 1 トラックの保存・交換 |
| `.PRT` | 選択トラックまたはパートの保存 |
| `.REX` | ユーザー・エクスクルーシブ一括定義 |
| `.RES` | ユーザー・エクスクルーシブ個別定義 |
| `.RAS` | 32 種類のリズム割り当て。名前、キー番号、ゲート等 |
| `.CM6` | CM-64 制御データ |
| `.GSD` | SC-55／GS 系制御データ |
| `.DEF` | 音源・音色定義 |

`.TRK`、`.PRT`、`.REX`、`.RES`、`.RAS` は、STed 専用の識別文字列を先頭に持つ固定形式である。互換保存では、識別文字列、ヘッダ長、トラック属性、終端レコード、文字列長を厳密に維持する必要がある。

### 9.3 外部変換

標準 MIDI ファイルなどとの変換は、設定ファイルに定義された外部プログラムを呼び出す構成である。したがって、次を区別する。

- STed 本体が直接読み書きする形式：RCP、R36 と専用補助形式。
- 外部変換を介して扱える形式：標準 MIDI、MCP、MTD 等、環境に導入された変換対象。

## 11. 初期状態

初期化時の代表値は次のとおり。

- 36 本の空トラックを生成。
- トラック番号は 1～36。
- 先頭 16 トラックは MIDI チャンネル 1～16、残りは OFF。
- 10 番トラックをリズムトラックとして初期設定。
- リズムトラックの K#+ は OFF。
- テンポ 120。
- タイムベース 48。
- 拍子 4/4。
- 調号 0。
- Play Bias 0。
- 全トラックの Mode は通常再生相当。
- 音源定義、音色割り当て、メモ、ユーザー・エクスクルーシブを初期化。

## 12. 容量・互換性上の制約

元文書・ソースから読み取れる主な制約は次のとおり。

- 最大 36 トラック。
- RCP は 18 トラック、R36 は 36 トラック。
- MIDI 論理チャンネルは A1～A16 と B1～B16 の 32 系統。RCD 内部には予備を含むチャンネル領域がある。
- 1 トラックの既定上限は約 64 KB、起動オプションで最大 256 KB まで拡張可能。
- 利用可能メモリに応じ、全体で約 589,356 ステップまで扱えるとマニュアルに記載。
- 楽曲タイトルは 64 文字。
- 楽曲メモは 12 行×28 文字。
- トラックメモは 36 文字。
- リズム割り当ては 32 種類。
- ユーザー・エクスクルーシブは 8 件、各 24 バイト程度。
- RCD のバッファ容量と X680x0 の空きメモリが、実質的な再生・録音上限になる。
- 旧環境の固定長フィールド、Shift-JIS 文字列、バイト単位のエンディアン／符号表現を互換実装で考慮する必要がある。

## 13. エラー・境界条件

確定仕様として、少なくとも次の状態を扱う必要がある。

- RCD が存在しない、または対応バージョンでない。
- MIDI インターフェースまたは外部音源へ接続できない。
- 音源定義ファイル、フォント、ヘルプ、外部プログラムが見つからない。
- RCP/R36 の識別文字列、ヘッダ、トラック終端が不正。
- 18 トラックを超えるデータを RCP として保存しようとする。
- トラック、録音、RCD 転送用のメモリが不足する。
- 既存ファイルがある場合のバックアップ・上書き確認。
- 録音中の MIDI 入力が不完全、running status が不正、エクスクルーシブが終端しない。
- 外部音源に対応しない特殊イベントやエクスクルーシブが含まれる。
- 同一小節参照、repeat、コメント、特殊イベントを含むトラックを部分再生する。
- 終了時に RCD の共有バッファへ書き戻すかどうか。

## 14. RCD との責務分担

STed と RCD の責務を、移植時にも混同しないよう次のように整理する。

| STed が担う | RCD が担う |
| --- | --- |
| 楽曲・トラックの編集 | 再生タイミングの実行 |
| RCP/R36 の読み書き | MIDI バイト列の送受信 |
| トラック属性・音色定義の管理 | 外部音源への出力 |
| 録音用イベントへの変換 | MIDI 入力バッファの提供 |
| 楽譜・グラフ表示 | 再生状態・現在位置の保持 |
| ユーザー操作、範囲編集 | 音源初期化データの受け取りと送出 |
| ポイント再生用データの生成 | 再生開始・停止・一時停止相当の制御 |

この分担から、STed のコードだけをビルドしても、元環境の MIDI 再生機能は完成しない。`RCDDEF.H` に定義された共有ヘッダと、`STED.C`／`FILE.C`／`RECORD.C` から確認できるドライバ呼び出しが元の実行契約である。

### 15.3 AudioUnit 優先方針に対する重要な事実

元の STed2.07m には、Audio Unit、AVAudioEngine、ソフトウェア音源、オーディオレンダリングの概念はない。元の「再生」は、RCD が MIDI メッセージを外部音源へ送信することを指す。

そのため、AudioUnit を最優先にする移植では、元の RCD の置き換えに相当する再生バックエンドを別途定義しなければならない。少なくとも次の二つは別の要件として切り分ける必要がある。

1. STed のイベント列を正確な MIDI イベント列へ変換し、Audio Unit 対応の音源へスケジュールすること。
2. 元の CM-64／SC-55／SC-88 向けエクスクルーシブや音源定義を、Audio Unit 音源でどう解釈・代替するかを決めること。

これは元仕様の再現ではなく、元の外部 MIDI 音源依存を新しい音源実行環境へ置き換える設計判断である。ハードウェア MIDI 対応は、この実行バックエンドとは独立した追加アダプタとして考えられる。

## 16. 受け入れ基準のたたき台

この仕様を移植プロジェクトの基準にする場合、まず次を満たすことを最小受け入れ条件とする。

### データ互換

- 付属サンプルの `.RCP`／`.R36` を読み込める。
- タイトル、メモ、テンポ、拍子、調、トラック属性、ノート、主要 MIDI イベントを保持できる。

- `.TRK`、`.PRT`、`.RAS`、`.REX` のうち、採用範囲を明示した形式を読み書きできる。

- 36 トラックを一覧・選択できる。
- ノートの挿入、削除、移動、コピー、範囲編集、クオンタイズができる。
- MIDI チャンネル、音色、音量、パン、エクスプレッション、ピッチ等を編集できる。
- SAME MEAS／repeat を含むトラックを再生・編集できる、または非対応範囲を明示的に検出できる。

### 再生・録音

- AudioUnit 優先の再生経路でノート、主要 CC、プログラム、ピッチ、テンポを正しい順序・時刻で出力できる。
- MIDI IN のノートオン／オフ、ベロシティ、CC、ピッチ、プログラムを録音できる。
- 録音したデータを STed のトラックとして保存・再生できる。
- 音が出ない場合に、音源未接続、未対応イベント、フォーマット不正などの原因を表示できる。

### 再現性

- 同じ入力データと同じテンポ設定から、macOS と iOS で同じ論理イベント列を生成する。
- UI やオーディオ実装に依存しないコアテストを用意する。

## 19. 移植ターゲットの追加前提

移植版は Swift／Xcode で macOS、iOS（iPhone／iPad）を対象とする。AudioUnit 経路をハードウェア MIDI より優先する。

RCP 再生については、次の既存実装を参照資料とする。

`/Users/ring2/Documents/src/Nuked-SC55-jcmoyer/Plugins`

この参照実装では、RCP v2 を JUCE 非依存の解析部で時刻付き raw MIDI イベント列へ変換し、AudioProcessor のオーディオ処理側でイベントを送出している。Swift 移植では、同じ挙動を `STedCore` と `AudioUnitAdapter` に分離して再実装する。既存コードをそのまま JUCE の依存ごと移植することは、今回の実装方針では採用しない。

AudioUnit 対応には「STed アプリが AudioUnit 音源をホストする」形と「STed 自体が AUv3 プレイヤーになる」形があり、これは次段階で決定する。どちらを選んでも、RCP/R36 の解析・編集モデルと時刻付き MIDI イベント展開は共通コアとして利用する。
